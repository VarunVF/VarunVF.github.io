Recently for fun, I had the idea of making a [small esolang](https://github.com/VarunVF/cell-80), which basically means a small esoteric programming language meant for fun or experiment rather than practical use.

## Idea

I was inspired by many of the tape-style esolangs that already exist, where the main theme is you control a pointer on a memory tape to modify cells and perform your task.

I thought, what if instead of modifying one cell at a time, you can modify ALL of them at once? This gave me the idea of having each column of a line operate on its own cell.

As for how many columns or cells there would be, I decided to borrow the limitation of 80 characters from the old IBM punched cards. As such, programs are fixed to 80 characters per line, no longer or shorter. Every character in a line operates on one of the 80 cells of memory.
(Within a single line, operations occur sequentially from left to right.)

### Syntax

The language is supposed to be abstract and confusing, so there are no alphabetical characters, only symbols. To explain the operations briefly:

- `#` : no-op
- `+` : increment cell
- `-` : decrement cell
- `,` : input an integer from user input
- `.` : print cell as ascii
- `:` : print cell as number
- `!` : set this line as the 'bookmark'
- `?` : jump to 'bookmark' if cell is not zero

## Evil Ideas

At first I wanted to use `_` as the no-op, but then I had the idea to use the much more noisy `#` instead, making source much more unreadable.

When the interpreter encounters an error, such as an invalid operation, it cannot continue safe operation, and thus all cells are reset to zero before resuming operation without warning.

## Example

Here is an example showing a simple loop (you may have to scroll to see the last column).

```c80
+###############################################################################
+###############################################################################
+###############################################################################
+###############################################################################
+###############################################################################
-+#############################################################################!
?###############################################################################
#:##############################################################################
```

What the code does:
- The first five lines increment cell 0 until it reaches a value of 5.
- Line 6 decrements cell 0 and increments cell 1.
- Line 6 also has `!` on the last column. It acts as a 'bookmark' for the loop to jump to that line on each iteration.
- Line 7 has `?` in the first column, so it compares the value of cell 0 to zero. If not zero it jumps to line 6 (the 'bookmark').
- Finally, on the last line, the value of cell 1 is printed as a number.

Overall, the loop effectively moves the value in cell 0 to cell 1, so the output is 5.

## Bonus: Hello World

I initially believed Hello World in this language would take hundreds of lines. Indeed my first naive attempt took about 120 lines, but by using a loop to accumulate the values I improved this to 67 lines.
